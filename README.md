CPU-Optimised Facial Analysis & Real-Time rPPG ApplicationThis application combines highly-optimised multi-task face tracking, demographic profiling (age, gender, ethnicity), facial expression mapping, and real-time remote photoplethysmography (rPPG) heart-rate tracking using a live webcam feed.The pipeline has been heavily refactored for stable, real-time performance on standard CPU hardware.Features & OptimisationsInsightFace Face Analysis: Detects the main face and extracts Age/Gender features out-of-the-box using the lightweight buffalo_l pack. Embedding generation (w600k_r50.onnx) is explicitly disabled to save massive CPU cycles.HSEmotion Expression Analysis: Classifies micro-expressions seamlessly using an integrated PyTorch EfficientNet-B0 backbone.FairFace Ethnicity Profiling: Identifies ethnicity demographics via an external, local ONNX runtime layer.Multi-Threaded Real-Time Video: Camera frames are ingested via a dedicated background worker thread to drop stale frames automatically, keeping visual tracking latency near zero.MediaPipe 478-Point Video Mesh: Smooth, high-performance tracking utilizing MediaPipe's sequential video processing framework (detect_for_video) to calculate forehead pixel coordinates.rPPG Vital Tracker: Isolates a dynamic Forehead Region of Interest (ROI) using the Plane-Orthogonal-to-Skin (POS) algorithm, a Butterworth bandpass filter, and Fast Fourier Transforms (FFT) to determine live Heart Rate (BPM).Technical Project ArchitectureEnsure your file tree matches this exact layout for the absolute path mapping routines to execute properly:textEmotion_Detection/

The Live Pulse wave and BPM tracking value are separated cleanly and rendered on a black high-contrast background bar directly underneath the bottom line of the tracking box.Running the ApplicationExecute the core script pipeline through your terminal terminal window:bashpython Emotion_Detection/main.py
